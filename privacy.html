Informativa sulla privacy

AudioOps · Ultimo aggiornamento: ottobre 2026

1. Titolare

Agustin Davrieux – contatto: agusdavri@gmail.com

2. Quali dati tratta l'app

  • Dati di lavoro inseriti dagli utenti: inventario, eventi, kit, documenti di trasporto, anagrafica dello staff tecnico (nome, ruolo, telefono, email), foto delle attrezzature.
  • Dati dell'account Google (solo se si effettua l'accesso): nome e indirizzo email, usati per mostrare il profilo nell'app.

3. Dove vengono conservati

  • Sul dispositivo dell'utente.
  • Nel Google Drive dell'amministratore, nella cartella «AudioOps Backups», sotto forma di file di backup.

AudioOps non dispone di server propri: nessun dato viene inviato allo sviluppatore o a terzi, né usato per pubblicità, profilazione o analisi.

4. Uso dei dati Google

L'app richiede questi accessi a Google Drive:

  • drive.file: creare, leggere ed eliminare solo i file di backup creati dall'app;
  • drive.readonly: trovare e scaricare la cartella di backup che un amministratore ha condiviso con l'utente.

L'app non legge, modifica né condivide altri file del tuo Drive. L'uso e il trasferimento delle informazioni ricevute dalle API di Google rispettano le Norme sui dati utente dei servizi API di Google, inclusi i requisiti di Uso limitato (Limited Use).

5. Permessi del dispositivo

  • Fotocamera: scansione codici a barre e foto delle attrezzature.
  • Libreria foto: scelta delle immagini delle attrezzature.
  • Calendario: aggiunta degli eventi, solo su richiesta dell'utente.

6. Conservazione e cancellazione

  • Dati sul dispositivo: si cancellano disinstallando l'app.
  • Backup su Drive: si cancellano eliminando la cartella «AudioOps Backups». L'app tiene automaticamente un numero limitato di backup e sposta quelli vecchi nel cestino di Drive.
  • Accesso Google: si revoca da myaccount.google.com/permissions.

7. Diritti

Puoi chiedere accesso, rettifica o cancellazione dei tuoi dati scrivendo a agusdavri@gmail.com.

8. Modifiche

Eventuali modifiche a questa informativa saranno pubblicate su questa pagina.
